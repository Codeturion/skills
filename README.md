Verified Unity agent skills ([skills.sh](https://skills.sh) standard): production workflows, terminal-first and headless. **Nothing ships unverified**: every command was run on a real Unity editor before it was written down.

[![Browse the skills](https://skills.fuatcankoseoglu.com/banner.svg)](https://skills.fuatcankoseoglu.com)

Every skill's full card, its verification record, per-skill install commands, and the roadmap live on **[skills.fuatcankoseoglu.com](https://skills.fuatcankoseoglu.com)**.

## Install

```bash
npx skills add Codeturion/skills
```

```text
/plugin marketplace add Codeturion/skills   # Claude Code
```

For a single skill, copy its exact install command from its card on [the site](https://skills.fuatcankoseoglu.com).
